# FYP 2026-2027
## Multi-Agent Medical Image Diagnosis System

### Project Overview

This final year project aims to develop a multi-modal medical image
diagnosis system combining specialized Convolutional Neural Network (CNN)
models with a multi-agent decision-making framework.

The system will analyze different types of medical images using
modality-specific CNN models. The predictions generated by these models
will then be provided to a multi-agent system, where multiple agents
will discuss and evaluate the available evidence before producing a
final conclusion.
